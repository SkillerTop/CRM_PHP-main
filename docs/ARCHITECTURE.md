# Архитектура CRM

## Backend

- `public/index.php` — единственная публичная точка входа API.
- `src/Http` — HTTP-запросы, ответы и маршрутизация.
- `src/Controller` — контроллеры API по доменам CRM.
- `src/Domain` — бизнес-правила, маппинг, аудит, напоминания и почта.
- `src/Database` — подключение к БД и выполнение миграций.
- `src/Security` — авторизация, пароли и ограничение запросов.
- `src/Config` — загрузка окружения и конфигурации.
- `database/migrations` — последовательные SQL-миграции.

## Frontend

- `app/CRMApp.tsx` — композиция приложения и orchestration серверных операций.
- `app/components` — переиспользуемые визуальные компоненты.
- `app/hooks` — клиентские React-хуки, связанные с состоянием интерфейса.
- `app/api-client.ts` — единый HTTP-клиент фронтенда.
- `app/url-filters.mjs` — чистые функции чтения и формирования URL-фильтров.
- `app/globals.css` — общая дизайн-система и адаптивные правила.
- `tests` — проверки поведения и responsive-ограничений.

## Правило дальнейших изменений

Новый переиспользуемый UI-код помещается в `app/components`, состояние и эффекты — в `app/hooks`, интеграция с API — в `app/api-client.ts` или отдельный сервисный модуль. Бизнес-правила не дублируются во фронтенде и должны оставаться в `src/Domain`/`srcController`.
